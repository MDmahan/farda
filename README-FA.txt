فردای من — بسته وب‌اپ قابل نصب (PWA)

برای اینکه روی آیفون از Safari به صفحه اصلی اضافه شود، این فایل‌ها باید روی یک آدرس HTTPS منتشر شوند.
این بسته به‌تنهایی هنوز آدرس عمومی اینترنتی ندارد.

روش انتشار ساده با GitHub Pages:
1) وارد github.com شو و یک حساب بساز/وارد شو.
2) یک مخزن جدید (Repository) بساز؛ مثلاً با نام fardaye-man.
3) همه فایل‌های این پوشه را در ریشه مخزن بارگذاری کن: index.html، manifest.webmanifest، sw.js، icon-192.png و icon-512.png.
4) در مخزن، Settings > Pages را باز کن.
5) در بخش Build and deployment، گزینه Deploy from a branch را انتخاب کن؛ Branch را main و پوشه را /(root) بگذار و Save کن.
6) پس از انتشار، GitHub یک آدرس HTTPS می‌دهد. آن را در Safari آیفون باز کن.
7) دکمه Share را بزن، سپس Add to Home Screen و بعد Add را انتخاب کن.

نکته:
- تا وقتی روی HTTPS منتشر نشده، نصب PWA از Safari کار نمی‌کند.
- داده‌های کارها روی همان دستگاه/مرورگر ذخیره می‌شوند و خودکار بین دستگاه‌ها همگام نمی‌شوند.
- یادآور داخل این نسخه وقتی صفحه باز باشد کار می‌کند؛ اعلان زمان‌بندی‌شده قابل‌اعتماد در پس‌زمینه نیاز به پیاده‌سازی و میزبانی سرویس اعلان جداگانه دارد.
